# Politique de mot de passe faible (CWE-521)

La version vulnérable n'exige qu'une longueur minimale de 6 caractères, sans aucune vérification contre les mots de passe les plus courants ou déjà compromis. Ces mots de passe faibles ou réutilisés facilitent grandement le brute force et le credential stuffing, puisqu'ils figurent souvent dans les listes exploitées par les attaquants. La correction porte l'exigence de longueur minimale à 12 caractères, conformément aux recommandations NIST 800-63B, sans imposer de règles de composition artificielles contre-productives, et ajoute une vérification du mot de passe choisi contre une liste de mots de passe compromis connus via `IPwnedPasswordChecker`. Aucune rotation périodique obligatoire n'est imposée sans motif de compromission avérée.
