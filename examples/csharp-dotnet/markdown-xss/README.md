# Markdown-based Cross-Site Scripting (CWE-79)

La version vulnérable convertit le Markdown soumis par l'utilisateur en HTML avec un pipeline Markdig qui autorise le HTML brut, puis renvoie ce HTML directement au navigateur sans aucune sanitisation. Un contenu Markdown contenant des balises HTML actives ou des attributs d'événements passe donc intact jusqu'au client, car le moteur de rendu Markdown n'a pas vocation à filtrer le HTML actif — ce n'est pas son rôle. La correction désactive le support du HTML brut dans le pipeline via `DisableHtml()`, ce qui neutralise déjà l'essentiel du risque, puis ajoute une seconde couche de défense en passant systématiquement le HTML produit dans `HtmlSanitizer` (Ganss.XSS) configuré avec une liste blanche stricte de schémas d'URL (`http`, `https`, `mailto`). Cette double barrière garantit qu'une éventuelle extension future du pipeline Markdown ne réintroduit pas silencieusement une faille.
