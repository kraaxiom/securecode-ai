# Blind Cross-Site Scripting (CWE-79)

La version vulnérable affiche le message d'un ticket support et le `User-Agent` du client — deux valeurs fournies par un utilisateur externe non authentifié — directement dans le HTML du tableau de bord d'administration, sans aucun encodage. Comme cette page n'est consultée que par des administrateurs, l'exploitation n'est pas immédiatement visible pour l'attaquant : le script injecté s'exécute de façon différée, dans un contexte à privilèges élevés que l'auteur de l'attaque ne peut observer directement, d'où le terme « aveugle ». La correction applique un encodage HTML contextuel via `HtmlEncoder` sur chaque champ externe avant insertion dans le balisage, y compris pour l'interface interne, en traitant toute donnée venant de l'extérieur du périmètre de confiance comme non fiable. Une Content Security Policy stricte sur les routes `/admin` est recommandée en défense en profondeur, au cas où un point d'encodage serait oublié ailleurs.
