# Brute Force (CWE-307)

La version vulnérable expose un endpoint de connexion sans aucune limitation du nombre de tentatives, ni par compte ni par adresse IP. Un attaquant peut donc soumettre un très grand nombre de mots de passe de façon automatisée jusqu'à trouver une combinaison valide, en particulier sur des comptes protégés par un mot de passe faible. La correction introduit un suivi des échecs (`ILoginAttemptTracker`) appliqué à la fois par compte et par IP, avec une fenêtre de verrouillage temporaire au-delà d'un seuil défini. Les échecs sont journalisés avec l'IP source, et le message d'erreur reste générique pour éviter l'énumération de comptes. Cette double limitation (compte + IP) empêche un attaquant de contourner le verrouillage en distribuant ses tentatives.
