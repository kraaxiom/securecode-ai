# Mutation-based Cross-Site Scripting / mXSS (CWE-79)

La version vulnérable "nettoie" le contenu d'un éditeur riche avec une expression régulière qui retire uniquement la balise `<script>` littérale, sans comprendre la grammaire HTML complète ni les comportements de reparsing du navigateur. Ce type de filtrage naïf échoue précisément contre le mXSS : le navigateur peut réinterpréter et normaliser différemment un markup jugé sûr par ce filtre lors de son insertion dans le DOM, faisant réapparaître une structure active après la vérification — la faille n'est donc pas dans la logique de filtrage elle-même mais dans le décalage entre ce que le filtre comprend et ce que le navigateur exécute réellement. La correction remplace ce filtrage par `HtmlSanitizer` (Ganss.XSS), une bibliothèque de sanitisation HTML maintenue et conçue pour tenir compte de ces quirks de parsing, avec une liste blanche stricte de balises et d'attributs. La re-sanitisation est aussi appliquée systématiquement à l'affichage, en plus de la sauvegarde, pour ne jamais présumer qu'un contenu déjà "nettoyé" reste sûr après un nouvel aller-retour.
