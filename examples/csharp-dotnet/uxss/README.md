# Universal Cross-Site Scripting (CWE-79 / CWE-1021)

La version vulnérable intègre une iframe tierce sans attribut `sandbox` et charge un script depuis un CDN sans vérification d'intégrité, sans qu'aucune Content Security Policy ni Permissions-Policy ne soit définie. Le UXSS désigne une classe de failles où la cause première se situe souvent hors du code applicatif (bug du moteur de rendu, extension de navigateur, compromission d'un composant tiers largement intégré) et permet de contourner la Same-Origin Policy pour exécuter du script dans le contexte de n'importe quel site visité ; l'absence de restrictions applicatives maximise alors l'impact d'une telle faille sur l'application. La correction n'élimine pas la cause du UXSS elle-même, mais réduit la surface d'exposition : l'iframe reçoit un attribut `sandbox` limité au strict nécessaire (`allow-scripts allow-same-origin`), le script tiers est chargé avec Subresource Integrity (`integrity` + `crossorigin`) pour garantir que seul le fichier vérifié s'exécute, et une Content Security Policy stricte restreint `script-src`/`frame-src` aux origines explicitement nécessaires, en complément d'une `Permissions-Policy` désactivant les capacités sensibles inutiles.
