# Broken Function Level Authorization (CWE-862)

La version vulnérable protège `DELETE /api/users/{id}` avec `[Authorize]` seul, ce qui garantit uniquement que l'appelant est authentifié, sans vérifier qu'il possède le rôle requis pour exécuter cette fonction sensible. N'importe quel utilisateur standard connaissant l'URL peut ainsi supprimer un compte, y compris un compte administrateur, en s'appuyant sur le fait que l'action n'est pas exposée dans l'interface (sécurité par obscurité). La correction ajoute une policy d'autorisation centralisée (`RequireAdminRole`) définie une seule fois et appliquée explicitement sur l'endpoint via `[Authorize(Policy = "RequireAdminRole")]`, garantissant qu'un contrôle de rôle serveur est systématiquement appliqué, indépendamment de la découvrabilité de la route côté client.
