# Memory Poisoning

La version vulnérable écrit automatiquement dans la mémoire persistante de l'utilisateur les faits extraits de chaque réponse de l'agent, sans confirmation explicite ni cloisonnement vérifié, puis réinjecte ce contenu tel quel comme contexte de confiance dans les sessions suivantes, permettant à une information fausse introduite une seule fois de compromettre durablement le comportement de l'agent (CWE-349, Acceptance of Extraneous Untrusted Data With Trust). La version corrigée exige une confirmation explicite de l'utilisateur avant toute écriture durable en mémoire, cloisonne strictement la clé mémoire par tenant/utilisateur, et revalide le contenu réinjecté aux sessions suivantes en le présentant au modèle comme une donnée à vérifier plutôt qu'une instruction de confiance absolue.
