# Jailbreak de modèle

La version vulnérable ne repose que sur le system prompt comme barrière de sécurité de l'assistant conversationnel, sans aucune couche de modération indépendante en entrée ou en sortie ni surveillance du nombre de tours utilisés pour tenter d'éroder progressivement ses restrictions, ce qui expose l'application à un contournement des garde-fous du modèle (CWE-1427, Improper Neutralization of Input Used for LLM Prompting). La version corrigée ajoute un classifieur de sécurité indépendant appliqué à la fois au message entrant et à la réponse sortante, et borne le nombre de tours suspects par session pour détecter les tentatives répétées de contournement, sans jamais manipuler de contenu de contournement lui-même — uniquement la structure défensive applicative.
