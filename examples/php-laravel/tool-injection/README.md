# Tool Injection

La version vulnérable exécute les appels d'outils générés par le modèle avec les arguments produits tels quels par le texte, sans validation de schéma, sans vérifier la confiance de la source des définitions d'outils, et sans liste blanche contextuelle, ce qui permet à un contenu externe non fiable traité par l'agent d'influencer quel outil est invoqué et avec quels paramètres (CWE-1427, Improper Neutralization of Input Used for LLM Prompting). La version corrigée valide chaque appel d'outil contre un schéma typé strict avant exécution, ne charge que des définitions d'outils issues de sources explicitement listées comme fiables, applique une liste blanche contextuelle selon le niveau de confiance du contenu traité, et journalise chaque exécution avec ses paramètres réels pour permettre l'audit.
