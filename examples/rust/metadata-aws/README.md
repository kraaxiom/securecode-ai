# SSRF vers le service de métadonnées AWS (IMDS)

`vulnerable.rs` récupère une URL fournie par l'utilisateur sans filtrer les plages d'adresses link-local, ce qui, sur une instance EC2/ECS utilisant encore IMDSv1, permet d'atteindre `169.254.169.254` et de récupérer les identifiants temporaires du rôle IAM attaché, correspondant à CWE-918 (Server-Side Request Forgery). `fixed.rs` bloque explicitement l'adresse de métadonnées en plus de la whitelist générale de domaines et du filtrage des plages privées/link-local, désactive les redirections automatiques, et suppose côté infrastructure une migration vers IMDSv2 (jeton de session requis) ainsi qu'un rôle IAM appliquant le moindre privilège. Cette correction applique la recommandation de `rules/remediation/metadata-aws.md` : filtrer explicitement `169.254.169.254`, migrer vers IMDSv2 et appliquer le principe du moindre privilège sur le rôle IAM attaché.
