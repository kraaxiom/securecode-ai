# Secret JWT faible — Signature HMAC prévisible

`vulnerable.rs` signe les JWT avec un secret HMAC court et codé en dur (`"secret123"`), permettant à un attaquant de le retrouver par force brute hors ligne ou par simple lecture du code source afin de forger des tokens valides, ce qui correspond à CWE-1391 (Use of Weak Credentials). `fixed.rs` charge le secret depuis une variable d'environnement avec une vérification explicite d'au moins 256 bits d'entropie, épingle strictement l'algorithme HS256 attendu à la vérification (rejetant tout `alg: none`), et applique une expiration courte aux tokens émis. Cette correction applique la recommandation de `rules/remediation/weak-jwt-secret.md` : générer le secret via un CSPRNG d'au moins 256 bits, le stocker hors du code, et vérifier strictement l'algorithme côté serveur.
