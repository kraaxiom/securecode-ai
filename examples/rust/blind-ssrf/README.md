# Blind SSRF

`vulnerable.rs` enregistre un webhook et déclenche une requête sortante asynchrone vers une URL fournie par l'utilisateur sans jamais renvoyer son résultat à l'appelant, sans aucune whitelist ni validation d'IP, ce qui correspond à CWE-918 (Server-Side Request Forgery) dans sa variante aveugle. `fixed.rs` applique les mêmes contrôles qu'une SSRF classique avant de lancer le job asynchrone — whitelist de domaines, résolution DNS puis validation de l'IP obtenue, redirections désactivées — et journalise chaque requête sortante validée pour permettre la détection a posteriori d'un scan interne. Cette correction applique la recommandation de `rules/remediation/blind-ssrf.md` : appliquer strictement les mêmes contrôles qu'une SSRF classique même en l'absence de retour visible, et journaliser les requêtes sortantes des workers asynchrones.
